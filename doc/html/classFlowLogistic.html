Detailed Description

Fluxo com equação de crescimento logístico.

Equação: execute() = 0.01 * target->getValue() * (1 - target->getValue() / 70.0)

Modela uma população com capacidade de suporte igual a 70 unidades. Criado exclusivamente via ModelFactory::createFlowLogistic.
