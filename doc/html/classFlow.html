Detailed Description

Interface abstrata de especificação para um Fluxo.

Representa a transferência de valor entre dois sistemas durante a simulação. Cada fluxo possui uma equação matemática (método execute()) que determina quanto valor é transferido do sistema de origem para o de destino a cada ciclo.
